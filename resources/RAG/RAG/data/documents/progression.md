Training Progression
What progression means

Progression means gradually improving what the body can do.

Progress does not always mean adding more weight.

Progress can mean:

More repetitions
More resistance
Harder variation
Better technique
Better range of motion
Better control
Longer running time
Faster running pace
Less rest when appropriate
Beginner progression

Beginners should first learn:

The exercise
Correct basic movement
Controlled repetitions
Consistent training

Then gradually increase difficulty.

Example push-up progression
Wall push-up
→ Incline push-up
→ Knee push-up
→ Standard push-up
→ Close-grip push-up
→ Decline push-up

The exact progression depends on the person's ability.

Example squat progression
Bodyweight squat
→ Controlled squat
→ Pause squat
→ Split squat
→ Bulgarian split squat
→ Loaded squat
Running progression

A beginner can progress from:

Walking
→ Walk/jog
→ Longer jogging periods
→ Continuous running
→ Longer runs
→ Faster running
Progressive overload rule

Only increase difficulty when the person can perform the current level consistently with acceptable technique.

Avoiding overtraining

Do not increase:

Volume
Intensity
Frequency
Speed

all at the same time.

Small changes are easier to recover from.

Tracking progress

Track:

Repetitions
Sets
Exercise variation
Form score
Running time
Distance
Pace
Rest
Personal bests

VYRA can use these values to show improvement over time.

VYRA adaptive progression

VYRA can use performance history to decide whether a challenge should:

Stay at the same level
Become slightly harder
Become slightly easier
Focus on form
Focus on endurance

Good form should be considered alongside repetition count.
